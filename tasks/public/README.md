# Public tasks

This directory will contain development tasks and public fixtures that a solving agent is permitted to inspect.

Each task must eventually include a machine-readable manifest declaring:

- Task identifier and defect family
- Issue instruction
- Public repository path
- Allowed commands
- Writable paths
- Protected paths
- Turn and timeout limits
- Public checks
- Expected output surface
- Structural-template cluster

Hidden interventions, oracle logic, final evaluation seeds, and independent-quality assets do not belong here.
